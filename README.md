## Featured Projects

### [CommitLoom](https://github.com/SupunLiyanage88/CommitLoom) — AI commit messages for VS Code
A VS Code extension that writes conventional commit messages from your staged diff, one click from the Source Control panel. Diffs are scanned for secrets before they leave your machine, API keys live in VS Code SecretStorage, and large diffs are truncated per file so context stays useful. Supports NVIDIA and OpenRouter, with a rated model picker and custom model IDs.

`TypeScript` · `VS Code API` · `NVIDIA NIM` · `OpenRouter`

### [FeedPulse](https://github.com/SupunLiyanage88/FeedPulse) — AI-assisted feedback triage
A product feedback platform with a public submission form and an authenticated admin dashboard. Gemini handles categorization, sentiment, priority scoring, tagging, and weekly trend summaries so triage doesn't have to be manual.

`Next.js` · `Express` · `MongoDB` · `Gemini` · `JWT`

### [Syndicate Esports](https://github.com/SupunLiyanage88/syndicate-esports) — Tournament platform
The official platform for Ascendant League Season 1, a Sri Lankan MLBB 5v5 tournament. Handles roster registration with Zod validation and IP rate limiting, an admin dashboard for approvals and settings, and an auto-seeded single-elimination bracket that advances winners as scores land.

`Next.js 14` · `TypeScript` · `MongoDB` · `Tailwind` · `Framer Motion`

### [RideOn](https://github.com/SupunLiyanage88/RideOn) — Rider safety and mobility
A smart mobility app focused on rider safety. Live location tracking with real-time routing, plus off-route and risk alerts that surface to an admin dashboard for oversight and ride history.

`TypeScript` · `Real-time tracking` · [`Backend`](https://github.com/akilaManu-MaHiTo/rideon-server)

### [BookHive](https://github.com/SupunLiyanage88/BookHive) — Library management system
Full-stack library platform covering the book catalogue and rental lifecycle, with Bearer-token JWT auth across a React frontend and a Spring Boot API.

`React 18` · `Spring Boot` · `Java 17` · `MySQL` · `MUI`

### [GlobePeek](https://github.com/SupunLiyanage88/GlobePeek) — Interactive country explorer
Browse and compare countries through an interactive world map, with search by name, capital, or language. Google auth via Firebase and Firestore-backed profiles keep favourites synced across devices.

`React` · `Vite` · `Firebase` · `REST Countries API` · `Tailwind`

### [BillCraft](https://github.com/SupunLiyanage88/BillCraft) — Invoice generator
Professional invoices in seconds with no signup required. Built on React 19 and MUI.

`React 19` · `TypeScript` · `Vite` · `MUI`

### Mobile

**[iOS Mini Projects](https://github.com/SupunLiyanage88/IOS-Mini-Projects)** — A set of SwiftUI apps built while working through core iOS concepts: animation, paginated onboarding, random selection, a component-driven forecast UI, and a Core ML trail risk predictor.

**[SpendSence V2.0](https://github.com/SupunLiyanage88/SpendSence_V2.0)** — A Kotlin personal finance app for Android covering onboarding, auth screens, and a dashboard with transaction lists. Firebase auth and persistence in progress.
